## 🧮 Calculator

The built-in calculator provides instant calculations without leaving the search interface.

### Basic Operations

| Operator | Example | Result |
|----------|---------|--------|
| `+` | `2+2` | 4 |
| `-` | `10-5` | 5 |
| `*` | `10*5` | 50 |
| `/` | `100/4` | 25 |
| `^` | `2^10` | 1024 |

### Scientific Functions

| Function | Example | Result |
|----------|---------|--------|
| Square root | `sqrt 144` | 12 |
| Cube root | `cbrt 27` | 3 |
| Sine | `sin 45` | 0.7071 |
| Cosine | `cos 60` | 0.5 |
| Tangent | `tan 45` | 1 |
| Logarithm (base 10) | `log 100` | 2 |
| Natural log | `ln 2.718` | 1 |
| Factorial | `5!` | 120 |
| Absolute value | `abs -5` | 5 |
| Percentage | `25% of 200` | 50 |

## 📁 File Search

Search files stored on your device.

### Search by Name
Type the file name or part of it:
```
quarterly-report
vacation-photo
important-document
```

### Search by Type
Type the file extension:
| Extension | File Type |
|-----------|-----------|
| `pdf` | PDF Documents |
| `doc` | Word Documents |
| `.xls` | Excel Spreadsheets |
| `.ppt` | PowerPoint |
| `.jpg` | JPEG Images |
| `.png` | PNG Images |
| `.mp3` | Music Files |
| `.mp4` | Video Files |
| `.zip` | Archives |
| `.apk` | Android Apps |

### Search by Category
| Query | Finds |
|-------|-------|
| `photo` | All images |
| `music` | All audio files |
| `video` | All videos |
| `download` | Downloads folder |
| `document` | Office documents |

### Supported File Types

#### Documents
- PDF (.pdf)
- Word (.doc, .docx)
- Text (.txt)
- Excel (.xls, .xlsx)
- PowerPoint (.ppt, .pptx)
- Rich Text (.rtf)

#### Images
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- WebP (.webp)
- SVG (.svg)

#### Audio
- MP3 (.mp3)
- WAV (.wav)
- FLAC (.flac)
- AAC (.aac)
- OGG (.ogg)

#### Video
- MP4 (.mp4)
- MKV (.mkv)
- AVI (.avi)
- MOV (.mov)

#### Archives
- ZIP (.zip)
- RAR (.rar)
- 7Z (.7z)
- TAR (.tar)

### Examples
```
spotify      → Opens Spotify
chrome       → Opens Chrome
settings     → Opens Settings

```

## ⚙️ Quick Commands

System-level commands for instant access.

### Settings Commands
| Command | Opens |
|---------|-------|
| `wifi` | Wi-Fi settings |
| `bluetooth` | Bluetooth settings |
| `display` | Display settings |
| `sound` | Sound settings |
| `battery` | Battery settings |
| `storage` | Storage settings |
| `apps` | App manager |
| `security` | Security settings |

### Action Commands
| Command | Action |
|---------|--------|
| `flashlight` | Toggle flashlight |
| `camera` | Open camera |
| `calculator` | Open calculator |
| `dnd` | Toggle Do Not Disturb |
| `airplane` | Toggle airplane mode |
| `location` | GPS settings |
| `hotspot` | Mobile hotspot |

### Web Commands
| Command | Action |
|---------|--------|
| `yt query` | YouTube search |
| `map place` | Google Maps |
| `g query` | Google search |
| `ddg query` | DuckDuckGo |
| `bing query` | Bing search |

## 📋 Clipboard History

Track and reuse copied content.

### Features
- Automatic clipboard capture
- Pin important items
- Quick copy action
- Persistent storage
- Clear history option

### Usage
1. Copy any text normally
2. Open QuickLaunch
3. Tap clipboard history
4. Tap any item to copy again

## 🌐 Internet Search

```
g kotlin android    → Google search

```
