# QuickLaunch Quick Start Guide

Get started with QuickLaunch in just a few minutes!

## 🚀 Installation

1. Download the latest APK from [DOWNLOAD.md](../DOWNLOAD.md)
2. Enable "Install from unknown sources" in Settings
3. Install and open QuickLaunch

## 📱 Opening QuickLaunch

There are multiple ways to access QuickLaunch:

### Method 1: Widget
Add the QuickLaunch widget to your home screen for instant access.

### Method 2: Quick Settings
Add the QuickLaunch tile to your quick settings panel.

### Method 3: App Icon
Tap the QuickLaunch icon in your app drawer.

## 🔍 Search Basics

### Type to Search
Simply start typing to see results from all categories:

| Type This | Example Result |
|-----------|----------------|
| App name | `spotify` → Opens Spotify |
| Math | `2+2` → `4` |
| Contact | `john` → John's contact card |
| File | `pdf` → List of PDF files |
| Command | `wifi` → Wi-Fi settings |

### Quick Actions
Results show quick action buttons:

- 📞 **Call** - Call a contact directly
- 💬 **Message** - Send an SMS
- 🔍 **Open** - Launch app or file
- ⚙️ **Settings** - Open app settings

## ⚙️ Quick Commands

Type these commands for instant access:

| Command | Action |
|---------|--------|
| `wifi` | Wi-Fi settings |
| `bluetooth` | Bluetooth settings |
| `flashlight` | Toggle flashlight |
| `camera` | Open camera |
| `dnd` | Do Not Disturb |
| `airplane` | Airplane mode |

### Web Commands
```
yt cat videos    → YouTube search
map restaurant   → Google Maps
ddg kotlin       → DuckDuckGo search
```

## 📁 File Search

Search files by type:

| Search | Finds |
|--------|-------|
| `pdf` | All PDF files |
| `photo` | All images |
| `.doc` | Word documents |
| `download` | Downloads folder |

## 📞 Contact Search

Search contacts by name:
1. Type a contact name
2. See contact card with actions
3. Tap to call, message, or email

## 📋 Clipboard History

- Automatically saves copied text
- Tap any item to copy again
- Pin important items

## ⚡ Settings

Access settings via the menu icon:

- **Search Providers** - Enable/disable search categories
- **Appearance** - Theme, font size
- **Privacy** - Clear history, data
- **About** - Version, licenses

## 💡 Tips & Tricks

1. **Use abbreviations**: Type `cam` instead of `camera`
2. **Search settings**: Type `display` to find display settings
3. **Quick math**: No need to open calculator app
4. **Unit conversion**: Type `100 km` for instant conversion
5. **File search**: Type file extensions directly

## 🔧 Troubleshooting

### QuickLaunch doesn't appear in widget list
- Make sure the app is installed correctly
- Try restarting your device

### Search results are slow
- Close background apps
- Restart QuickLaunch

### Permissions not working
- Go to Settings → Apps → QuickLaunch → Permissions
- Enable the required permissions
