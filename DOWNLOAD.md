### Installation Instructions

#### Step 1: Download the APK

Click the download link above to download the QuickLaunch APK file to your device.

#### Step 2: Enable Unknown Sources

Before installing, you need to enable installation from unknown sources:

**Android 8.0 (Oreo) and later:**
1. Go to **Settings** → **Apps & notifications**
2. Tap **Special app access**
3. Select **Install unknown apps**
4. Find your browser (Chrome, Firefox, etc.)
5. Enable **Allow from this source**

**Android 7.0 (Nougat) and earlier:**
1. Go to **Settings** → **Security**
2. Toggle **Unknown sources** ON
3. Confirm the warning

#### Step 3: Install the APK

1. Open the downloaded APK file (usually in Downloads folder)
2. Tap **Install** when prompted
3. Wait for installation to complete
4. Tap **Open** to launch QuickLaunch

#### Step 4: Grant Permissions (Optional)

QuickLaunch will ask for permissions when you need them. All permissions are optional:

| Permission | Purpose |
|-----------|---------|
| Storage | Search files on your device |
| Contacts | Search and call contacts |
| Phone | Make calls directly |
| Accessibility | Use swipe gesture to open |
| System Settings | Add to quick settings |

## Troubleshooting

### Installation Failed

1. Make sure Unknown Sources is enabled
2. Check if you have enough storage space
3. Try downloading the APK again
4. Clear browser cache and try again

### App Won't Open

1. Restart your device
2. Check if your Android version meets requirements
3. Try clearing app cache in Settings → Apps → QuickLaunch

### Permissions Denied

The app works without permissions but with limited features. Grant permissions as needed for full functionality.
