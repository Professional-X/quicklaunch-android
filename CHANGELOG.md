# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Initial Release

### Added

- **Universal Search Launcher** - Main application for Android
- **Calculator** - Basic and scientific calculator with unit conversions
- **File Search** - Search files by name, type, or extension
- **App Launcher** - Quick launch any installed application
- **Contact Search** - Search contacts and perform quick actions
- **Clipboard History** - Track and manage clipboard items
- **Settings Search** - Quick access to Android settings
- **Quick Commands** - System commands (wifi, bluetooth, flashlight, etc.)
- **Internet Search** - Search using Google, DuckDuckGo, Bing, or Brave
- **Privacy-First Design** - No data collection, all processing local
- **Clean Architecture** - Modular provider system
- **Widget Support** - Home screen widget
- **Quick Settings Tile** - Quick access from notification shade
- **Open Source** - Full source code available under MIT License

### Features

- Search apps, files, contacts, settings, and the web from one interface
- Built-in calculator with scientific functions
- Unit conversions (length, weight, temperature, currency, etc.)
- Quick commands for system settings
- No root required
- Material Design 3 UI
- Dark mode support

### Technology Stack

- Kotlin programming language
- Jetpack Compose for modern UI
- Hilt for dependency injection
- Room database for local storage
- Kotlin Coroutines and Flow for async operations
- MVVM architecture pattern
- Minimum SDK: API 24 (Android 7.0)
- Target SDK: API 34 (Android 14)
